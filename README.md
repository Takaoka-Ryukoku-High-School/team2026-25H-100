# クラスボード

Python と Flet で作った、授業に関する情報を科目ごとに登録・確認するアプリです。

- テスト範囲や日程の登録・編集・削除
- 提出物の登録と提出済みチェック
- 提出物タブにクラス内の未提出数を表示
- 授業の進度や次回予定の記録
- 変更や締切の直前に通知を表示
- クラス単位の通知履歴と通知の確認操作
- 通知から関連する提出物・授業進行度・テスト範囲へ移動
- 学年・クラスごとの表示切り替え
- 教科の追加と切り替え
- 登録内容のローカル保存

一年生は1〜7組、二年生は1〜7組とアート・L&S・デジタルの各コース、三年生は1〜6組を選べます。情報は学年・クラス/コース・教科ごとに分けて表示されます。

二年生のアートコースでは、教科はコミックアート、デジタルアート、アートマネジメントの3つに限定されます。
二年生のデジタルコースでは、教科はBiz、Tech、テクアドの3つに限定されます。

初回起動時には操作を試せるサンプルが表示されます。情報は起動した環境のホームディレクトリにある `~/.classroom_board.json` に保存されます。既存の保存情報は一年生1組に移行します。現状は同じ環境内で使う試作版で、別の端末との同期やユーザー認証には対応していません。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。
