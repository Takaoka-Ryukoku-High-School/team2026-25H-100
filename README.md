# クラスボード

Python と Flet で作った、授業に関する情報を科目ごとに登録・確認するアプリです。

- テスト範囲や日程の登録・編集・削除
- 提出物の登録と提出済みチェック
- 授業の進度や次回予定の記録
- クラス・科目の追加と切り替え
- 登録内容のローカル保存

初回起動時には操作を試せるサンプルが表示されます。情報は起動した環境のホームディレクトリにある `~/.classroom_board.json` に保存されます。現状は同じ環境内で使う試作版で、別の端末との同期やユーザー認証には対応していません。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。
